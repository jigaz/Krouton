Krouton

Native optical disc mastering, verification, and burning for macOS.

Krouton is a modern disc authoring and burning application for CD, DVD, and Blu-ray media—built for deterministic builds, cryptographic read-back verification, and local or headless network drives.

Headless Network Server (krouton-spoold)

Need to burn to drives attached to a headless Mac mini, Raspberry Pi, Linux NAS, or Windows box across your LAN? Krouton pairs with krouton-spoold, a zero-CA mTLS (TLS 1.3 pinned certificate) remote burning daemon.
