Report a drive

Burners are getting rarer, and so is knowledge of their quirks. Every report helps Krouton handle your drive properly and goes into an open record anyone can use, at archive.krouton.app.

What to include

  • The drive’s maker and model, and its firmware version if you know it. On a Mac, System Information lists them under Disc Burning.
  • How it’s connected: built in, USB, Thunderbolt, or on a Krouton Server (and which computer).
  • The discs you used: type, brand and the speed printed on the packaging.
  • What happened: burned and verified, failed partway, or burned but wouldn’t read back. Krouton’s burn report has the details; paste it in.

Open a drive report on GitHub

No GitHub account? Email the same details to jorgen@krouton.app. Reports are published without your name unless you add it.
