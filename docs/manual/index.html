Krouton manual

How to make data discs, audio CDs and labels with Krouton, burn on another computer, and fix what goes wrong. The same manual is inside the app under Help.

  • Getting started. Krouton makes CDs, DVDs and Blu-ray discs on a Mac. It burns data discs that open on any computer, Blu-ray and DVD video you've already authored, and disc images you already have. It rips audio…
  • Data discs and disc images. Pick a data format in the Format Chooser, under Data & Archival Media, or from the Format menu.
  • Audio CDs. Krouton renders the disc exactly as the editor plays it, pauses and crossfades included, and writes it in one pass (session-at-once) with the ISRCs, the UPC/EAN as the disc's catalog number, and…
  • Burners, copies and the queue. The right-hand column lists where the disc goes. Each destination is a card. File › Add Destination Card (⇧⌘D) adds one; right-click a card for Run This Card Only, Eject Disc and Remove…
  • Burning on another computer. Krouton Server is a small program you install on another computer that has a burner: a Raspberry Pi, a Linux box, a Proxmox host, a NAS, a Windows 10 or 11 PC, or an older Mac. After you pair it…
  • Disc labels. The Label workspace (⌘4) designs printable disc faces at true size: 120 mm for standard discs, 80 mm for mini discs, with the centre hole shown so nothing important lands on it.
  • Video, copying and other formats. Parts of this chapter describe features that are still being built. Each section says where things stand.
  • Command line and Shortcuts. Run Krouton with a subcommand and it works in the terminal without opening a window. Inside the app bundle the program is Krouton.app/Contents/MacOS/Krouton; link it into your path as krouton.
