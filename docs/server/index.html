Krouton Server

Plug a burner into a spare computer, pair it with your Mac once, and pick it in Krouton like any other drive. The Mac sends the disc, the server burns it and reads it back to check, and progress shows up in Krouton as it happens.

The Linux builds are self-contained, so one file runs on any distribution. There is no published release yet: each build is produced by the project’s automated checks on GitHub, and you can also build it yourself with cargo build --release -p krouton-server.

Setting it up

  1. Copy the build onto the computer with the burner and run its installer: sudo deploy/linux/install.sh ./krouton-server on Linux, deploy/macos/install.sh ./krouton-server on a Mac, or deploy\windows\install.ps1 in an administrator PowerShell on Windows. The installer starts the service and runs a self-check.
  2. Open pairing on the server with krouton-server pair. In Krouton, open Settings, go to Burners & Network and choose the server under Krouton Servers.
  3. Both screens show the same six-digit code. Confirm it on both, and the server is paired.

To try the whole flow without a burner, set backend = simulate in the server’s server.conf.

Folders, not just disc images

Krouton can send a folder and let the server build the disc. The server checks every file name first, so a name Windows or a disc can’t hold is reported before anything is burned. Linux servers write ISO 9660 with Joliet and Rock Ridge; Mac and Windows servers add UDF.

Security

  • The server only answers computers on your own network unless you allow a VPN range yourself.
  • Pairing needs a person at each end to confirm the same code, and the two machines remember each other’s keys. There are no passwords or accounts.
  • Every connection is encrypted, and each Mac only ever sees its own burn jobs.
