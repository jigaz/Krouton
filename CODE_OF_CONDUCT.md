# Code of conduct

Krouton follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in this repository's issues, pull requests and reviews, and anywhere else you represent the project.

In short: be welcoming and patient, and criticise ideas and code rather than people. Harassment, insults and personal attacks are not accepted. The Covenant's full text is the one that applies.

## Reporting

Report unacceptable behaviour to **jorgen@krouton.app**. Reports are read only by the maintainer and handled in confidence. The maintainer decides on consequences following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).

For security problems, see [SECURITY.md](SECURITY.md) instead.
